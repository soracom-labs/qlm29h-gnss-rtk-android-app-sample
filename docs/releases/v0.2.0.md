# v0.2.0 Public Sample

> Draft: 組織管理のリリース鍵による署名、公開候補APKの実機確認、配布主体による最終確認が完了するまで公開しません。

QLM29HBAA-GMをAndroid端末へUSB接続し、NTRIP補正を利用したGNSS/RTK測位を確認するための公開サンプル版です。公式製品または公式サポート対象ではありません。

## リリース情報

- App version: `0.2.0` (`versionCode 2`)
- Source commit: 公開時に`main`の対象コミットを記載
- Package: `jp.co.soracom.qlm29hrtk`
- Supported Android: Android 14（API 34）以上
- Confirmed GNSS device: Quectel QLM29HBAA-GM
- Signing: 組織管理のリリース鍵（公開前に署名者を確認）
- License: MIT License

## v0.1.0 Evaluation 1からの主な変更

- NTRIP切断時の段階式再接続と、RTCM無受信タイムアウトを追加
- VPNだけが残った状態をOnlineとしないInternet表示へ改善
- Internet状態とNTRIP再試行を、認証情報や座標を含まない診断履歴として表示
- 過去セッションへ同じ走行中に記録したSmartphone GNSS軌跡を重ねる処理を改善
- GGAのUTC秒を基準に測位点を保存し、受信間隔の揺れによる欠落を抑制
- 正確な位置履歴、NMEA/RTCMログ、NTRIP認証情報をAndroidバックアップ対象外へ変更
- 公開用ドキュメント、CI、Issueテンプレート、セキュリティ窓口、MIT Licenseを整備

## 既存評価版からの移行

`v0.1.0 Evaluation 1`はAndroidのデバッグ鍵、この公開サンプル版は組織管理のリリース鍵で署名します。署名が異なるため、評価版APKへは上書きインストールできません。必要なセッションログをアプリから共有・エクスポートした後、評価版をアンインストールして本版を新規インストールしてください。アンインストールすると端末内の設定、測位点、セッションおよび生ログは削除されます。

## 既知の制約

- RTK Fixedへの遷移や維持は、上空視界、衛星配置、アンテナ、基準局、補正データ、通信品質、速度、マルチパスなどに依存し、保証されません。
- 本アプリは測量成果、ナビゲーション、運転支援または安全判断には使用できません。
- Map、NTRIP、SORACOM送信には、用途に応じたインターネット接続と外部サービス設定が必要です。
- OpenFreeMapの公開インスタンスにはSLAと個別サポートがありません。
- Android端末メーカー独自の省電力制御により、長時間のバックグラウンド動作が制限される場合があります。
